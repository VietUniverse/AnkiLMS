## Mẫu câu và biểu thức
- `저작권` / `불법 다운로드` / `개인 정보 유출` — bản quyền / tải lậu / rò rỉ thông tin.
- `생태계를 보존하다` — bảo tồn hệ sinh thái (`보존하다` = 잘 지키다).
- `균형 발전` / `지속 가능한 사회` — phát triển cân bằng / xã hội bền vững.
- `전통문화를 보전하다` — gìn giữ văn hoá truyền thống.
- `다양성을 존중하다` / `배려하다` — tôn trọng đa dạng / quan tâm.
- `획일화 사회` / `개성 없는 사회` — xã hội đồng nhất / thiếu cá tính.
- `끈기` = `인내심`, `빨리 포기하지 않고 끝까지 최선을 다하는 능력` — định nghĩa nên học thuộc.
- `… 때문에 그렇습니다` / `…기 때문이죠` — trả lời nguyên nhân; `이런 문제를 해결하기 위해서 어떻게 해야 합니까?` — khung câu hỏi giải pháp.
