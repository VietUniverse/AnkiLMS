# Cặp từ số liệu dễ lẫn

Cặp phân biệt bắt buộc khi nêu số: 이상 (từ N trở lên) / 이하 (từ N trở xuống) / 미만 (dưới N, không gồm N); 이후 (sau) / 이전 (trước); 인상 (tăng giá) / 인하 (giảm giá); 급격하다 (dốc) / 완만하다 (thoải); 주춤 (chững lại) cho biểu đồ chữ V; 평균 이상 (trên trung bình).

## Mẫu câu

- `2030년에는 흡연율이 5% 미만으로 감소할 것으로 전망된다.`
- `2020년 잠시 주춤한 후 2021년 다시 증가하였다.`
